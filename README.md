# Task Board

Лёгкий таск-менеджер прямо в VS Code. Никаких `// TODO` и `.md` файлов с задачами.

## Возможности
- **Боковая панель**: задачи по группам (Not started / In progress / Done), сортировка, фильтр по типу.
- **Dashboard** (иконка в заголовке панели или клик по счётчику в статус-баре): канбан-доска с drag & drop и список, поиск, фильтры по типу и автору, сортировка, прогресс.
- **Типы**: fix, refactor, feature, docs, test, idea. **Приоритеты**: low / medium / high.
- **Done = скрыто, не удалено**: после отметки приходит уведомление «Undo», завершённые показываются кнопкой-глазом и восстанавливаются в один клик.
- **Привязки** к файлам, папкам и строкам: ПКМ в Explorer -> *Link to Task...*, ПКМ по выделенному коду -> *Create Task from Selection* / *Link Selection to Task*.
- **Задачи прямо в файле**: над привязанной строкой появляется свёрнутая плашка с названием задачи, клик раскрывает её (открыть задачу, сменить статус, Done), привязанные строки подсвечены. Отключается настройкой `taskBoard.showInEditor`.
- **Команда**: автор (из `git config user.name`), даты, список обновляется после `git pull`.

## Хранение
Одна задача = один файл `.tasks/<id>.json`. Коммить папку `.tasks/` в git, и вся команда видит те же задачи; конфликты слияния почти невозможны.

## Запуск для разработки
```
npm install
npm run compile
```
Открой папку в VS Code и нажми **F5**.

## Сборка .vsix
```
npx @vscode/vsce package
code --install-extension task-board-0.1.0.vsix
```
